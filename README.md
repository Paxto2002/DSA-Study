## &nbsp; 🧭 &nbsp; What is this?

This repository is my **deep-dive into Data Structures & Algorithms** — not to rush through a checklist, but to genuinely *understand*, *implement*, and *internalize* every concept from the ground up.

**Two tracks. One goal:**

- 🔧 **C / C++** — for raw implementation, pointer mastery, memory management, and understanding *how things actually work* at the machine level
- 🐍 **Python** — for AI/ML/DS-oriented DSA, pattern thinking, and problem-solving fluency via the **Chai aur DSA** series by [Chai aur Code](https://www.youtube.com/@chaiaurcode)

Both tracks feed into **LeetCode problem solving** — where theory meets the real test.

> *"Don't just code — pause, think, and internalize."*

## &nbsp; 📊 &nbsp; Topics Overview

<details open>
<summary><b>🔧 &nbsp; Track 1 — C / C++</b> &nbsp; <i>Internal logic, memory, and true implementation.</i></summary>
<br/>

| 📌 Topic | 📖 What's Covered |
|---|---|
| Basics & Complexity | Time/space analysis, Big-O, patterns |
| Arrays & Strings | In-place operations, two pointers, sliding window |
| Pointers & Memory | Heap vs stack, pointer arithmetic, dynamic allocation |
| Recursion | Call stack, backtracking, recursive thinking |
| Sorting & Searching | Bubble, merge, quick, binary search — from scratch |
| Linked Lists | Singly, doubly, cycle detection, reversal |
| Stacks & Queues | Implementation, monotonic stack, queue variants |
| Trees & BST | Traversals, height, LCA, balanced trees |
| Graphs | BFS, DFS, Dijkstra, Union-Find, topological sort |
| Dynamic Programming | Memoization, tabulation, classic patterns |

</details>

<br/>

<details open>
<summary><b>🐍 &nbsp; Track 2 — Python (Chai aur DSA)</b> &nbsp; <i>Pattern thinking for AI, ML, and data science.</i></summary>
<br/>

| 📌 Topic | 📖 What's Covered |
|---|---|
| Python Foundations | Data types, comprehensions, built-ins |
| Arrays & Lists | NumPy-aware operations, Pythonic patterns |
| Recursion | Functional approach, generators |
| Sorting & Searching | `sorted()` internals, bisect, custom comparators |
| Linked Lists | Class-based implementation |
| Stacks & Queues | `deque`, `heapq`, priority queues |
| Trees | Recursive + iterative traversals |
| Graphs | Adjacency list, BFS/DFS for ML pipelines |
| Dynamic Programming | Bottom-up, top-down, real-world DS applications |
